# Сайт-поздравление 💜

Готовый **мобильный** сайт из пяти экранов: начало → поздравление → воспоминания → мини-игра с Джинкс → финальный сюрприз. Работает как статический сайт на GitHub Pages.

## Как открыть
1. Открой всю папку `secret-birthday-site` в VS Code.
2. Открой `index.html` через расширение Live Server (или просто двойным кликом).
3. Для публикации загрузи содержимое папки в GitHub-репозиторий. В **Settings → Pages → Build and deployment** выбери **Deploy from a branch → main → /(root)**.

## Как добавить ваши фотографии
Положи 3 фотографии с названиями `memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg` в папку `assets`. Если хочешь больше фото или поменять подписи, отредактируй массив `memories` в `script.js`. Пока фото нет, показаны красивые заглушки.

## Как добавить музыку
Помести собственный / разрешённый к использованию MP3 в `assets/music.mp3`. В браузерах телефона музыка **не запускается автоматически**, поэтому есть кнопка «Включить музыку». Коммерческие OST не включены в архив из-за авторских прав; для публичного GitHub Pages используй музыку, которую можно законно размещать.

## Как менять текст
Открой `index.html` и поменяй содержимое тегов `<h1>`, `<h2>`, `<p>`. Сейчас сохранено поздравление с 22-летием из вашего скриншота, проверь возраст и текст перед публикацией.

## Как вставить в существующий сайт
Если уже есть свой `index.html`, рекомендуем сделать копию старой версии. Этот проект самодостаточный: можно использовать как новый сайт, а не пытаться дописать поверх неизвестной структуры. Все пути относительные, поэтому GitHub Pages работает и в репозитории-подпапке.

## Файлы
- `index.html` — структура всех экранов.
- `style.css` — фиолетовое оформление с приоритетом телефона.
- `script.js` — навигация, галерея, мини-игра, подарок, конфетти, плеер.
- `assets/` — PNG персонажей, референс дизайна, место для ваших фото и MP3.


## Обновлённая тема
Версия в духе оригинального скриншота: тёмно-фиолетовый градиент, маленькие парящие сердечки, звёзды и мягкое сиренево-розовое свечение. Изображения персонажей оставлены небольшими, интерактивность сохранена.
